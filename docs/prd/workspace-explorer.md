# Workspace Explorer PRD

## 背景与目标

Explorer 是 Pi 与所有 Agent 共享的项目文件入口，需要覆盖高频浏览和管理操作，同时严格限制服务端可访问目录。

## 已实现范围

- 文件树展开、折叠、刷新和折叠全部。
- 文件搜索及键盘方向键选择、Enter 打开。
- 新建文件、文件夹，重命名、删除和复制路径。
- 文件与文件夹上传。
- 显示或隐藏点文件。
- Git 文件状态标识。
- 文件在中央或右侧标签中打开，并支持外部修改同步。
- Session/项目切换时刷新树和 Git 状态。

### 目录选择器

- 路径输入、进入父目录和选择当前目录。
- 隐藏目录图标开关，并记住选择。
- 最近项目快捷入口。
- `↑`、`↓`、Home、End 和 Enter 键盘导航。
- Esc、遮罩点击关闭。

## 安全边界

- `/api/files` 不是任意文件系统浏览器。
- 可访问根目录来自 Session cwd、项目根、受管默认目录和显式授权目录。
- 路径必须规范化并防止越过允许根目录。
- 删除等破坏性操作需要确认并返回明确错误。

## 验收标准

- 搜索结果可全键盘操作。
- 切换项目后不会显示上一个项目的文件树。
- 隐藏文件开关同时影响列表数据和图标状态。
- 无权访问、文件不存在和并发修改均有可见反馈。

## 后续计划

- 文件收藏、最近文件和跨项目搜索。
- 拖放移动及复制文件。
- 新建项目模板和更完整的文件预览。
- 大仓库文件索引进度与取消操作。
