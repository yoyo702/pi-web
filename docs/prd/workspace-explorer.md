# Workspace Explorer PRD

## 背景与目标

Explorer 是 Pi 与所有 Agent 共享的项目文件入口，需要覆盖高频浏览和管理操作，同时严格限制服务端可访问目录。

## 已实现范围

- 文件树展开、折叠、刷新和折叠全部。
- 文件搜索及键盘方向键选择、Enter 打开。
- 新建文件、文件夹，重命名、删除和复制路径。
- 文件与文件夹上传。
- 默认隐藏点文件和 `dist`、`.next`、`build` 等生成目录，支持统一显示开关。
- macOS `._*` 元数据文件始终过滤，不污染文件树和搜索结果。
- Git 文件状态标识。
- 文件在中央或右侧标签中打开，并支持外部修改同步。
- 二进制文件不再以乱码文本展示：读取时嗅探文件头是否包含 NUL 字节，识别为二进制后显示 "Binary file" 占位提示，仍可下载。
- 超过 256 KB 的文件不再直接报错：提供 "Show first 256 KB" 按钮读取前 256 KB 预览，工具栏标记 "Truncated" 且禁止编辑。
- 文本文件可编辑并保存；保存前会校验文件自上次读取后是否在磁盘上被修改（对比 mtime 和文件大小），发生变化则拒绝保存并提示重新加载（点击 "Reload" 会先确认再丢弃当前草稿并刷新为磁盘最新内容）。截断显示或二进制文件不可编辑；不是有效 UTF-8 的文本文件（如 GBK、Shift-JIS、Latin-1 编码）仍可查看（无法解码的字节显示为替换字符），但标记为只读（"Read-only · Not UTF-8 text"），Edit 按钮禁用，写入接口也会拒绝保存磁盘上不是有效 UTF-8 的文件，避免保存时破坏原有字符；通过聊天会话引用打开的工作区外文件同样只读。点击 Edit 会自动切换到 Source 视图显示编辑器（例如默认以 Preview 打开的 Markdown），编辑期间 Preview/Diff 切换按钮禁用。保存请求体上限 1 MB，超出返回 413。写入时先写入同目录下的临时文件再原子替换目标文件（`rename`），避免并发读取到写到一半的内容；临时文件直接以原文件的权限位创建（不会以默认权限短暂暴露 0600 等文件的内容），仅保留原文件的权限位，owner、扩展属性（xattrs）、硬链接等元数据不保证保留。编辑区域会保留原始的 CRLF/LF 换行风格（浏览器 textarea 会将 CRLF 归一化为 LF，保存前会还原）。切换文件标签、关闭文件标签、切换到 Git 面板、切换或关闭项目、以及重命名一个正在编辑的文件时，若存在未保存的修改会先弹出确认框，取消则保留原状态和草稿不变。在聊天中点击指向当前正在编辑的同一文件的链接不会弹框，也不会丢弃草稿。
- 文件标签支持鼠标滚轮横向滚动、锁定、批量关闭、复制完整路径和在 Explorer 中定位。
- Session/项目切换时刷新树和 Git 状态。
- 搜索支持按文件名或按文件内容切换：内容搜索在 Git 仓库内使用 `git grep`，非 Git 目录使用有限制的文件遍历回退（最多扫描 5000 个文件、跳过二进制和超过 1 MB 的文件；该回退没有超时，靠数量上限控制开销）；结果数量和扫描范围都有上限，点击结果会打开文件（不跳转到具体行）。

### 目录选择器

- 路径输入、进入父目录和选择当前目录。
- 隐藏目录图标开关，并记住选择。
- 最近项目快捷入口。
- `↑`、`↓`、Home、End 和 Enter 键盘导航。
- Esc、遮罩点击关闭。

## 安全边界

- `/api/files` 不是任意文件系统浏览器。
- 可访问根目录来自 Session cwd、项目根、受管默认目录和显式授权目录。
- 显式授权根目录持久化到 `~/.pi-web/allowed-roots.json`，恢复项目和服务重启后重新校验。
- 路径必须规范化并防止越过允许根目录。
- 删除等破坏性操作需要确认并返回明确错误。

## 验收标准

- 搜索结果可全键盘操作。
- 切换项目后不会显示上一个项目的文件树。
- 隐藏/生成文件开关同时影响目录列表与搜索，`._*` 始终不可见。
- 从文件标签执行“在 Explorer 中定位”时会展开父目录、选中并滚动到目标文件。
- 无权访问、文件不存在和并发修改均有可见反馈。
