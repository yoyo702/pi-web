# 响应式工作区布局 PRD

## 背景与目标

TianForge pi 同时承载聊天、Session、Explorer、Terminal 和 Git Review。布局需要在桌面端支持高信息密度，在移动端保持核心任务可完成。

## 已实现范围

### 桌面端

- 项目栏、左侧栏、中央工作区和右侧面板组成四段布局。
- 左侧栏和右侧面板可拖动调整宽度并持久化。
- Session 与 Explorer 区域可垂直拖动。
- 右侧面板内部列表与详情区域可调整尺寸。
- 中央工作区支持 Pi、Agent、Terminal 和文件多标签。
- 标签栏支持滚轮横向滚动和右键管理；锁定标签不会被批量关闭。关闭运行中的终端标签或运行中、等待审批的聊天标签前先确认，可选择保持运行或停止。
- 中央工作区标签栏同样支持右键的"关闭其他"/"关闭全部"；批量关闭时逐个走原有的运行中终端/聊天确认弹窗，不会跳过确认。
- 中央工作区标签支持拖拽排序；固定的 "TianForge pi" 标签始终排在第一位，不可拖动，也不能被拖到它前面。
- 关闭工作区标签（终端或聊天）后可通过 `Cmd/Ctrl + Shift + T` 撤销：单个关闭撤销这一个标签，"关闭其他"/"关闭全部"整批关闭时撤销同一批全部标签，最近 10 次关闭操作保留在历史中可依次撤销；若此时项目关闭撤销正处于 6 秒窗口内，同一快捷键优先撤销项目关闭。撤销历史按项目（cwd）分别保存，每个项目各自最多 10 批；打开其他弹窗或菜单时该快捷键不生效。重新打开的标签会追加到标签栏末尾。批量关闭时空闲标签立即关闭，运行中/繁忙标签逐个弹窗确认；点击 Cancel 会停止剩余的确认队列，未处理的标签保持打开，`Cmd/Ctrl + Shift + T` 只会重新打开这批里真正被关闭的标签。注意在普通浏览器标签页中 Chrome 会保留 `Cmd/Ctrl + Shift + T` 用于恢复被关闭的浏览器标签，该快捷键需要在已安装的 PWA（独立窗口模式）中才能生效。
- 仅有 Pi 标签时隐藏标签栏，保持原始简洁模式。
- 右侧面板支持聚焦放大与恢复。
- 右侧面板标题栏提供始终可见的收起按钮，收起后右上角保留成对的展开入口。

### 移动端

- 左侧栏改为覆盖式抽屉。
- 项目栏改为顶部项目切换器；侧边抽屉展开时该切换器隐藏，避免其浮层遮挡抽屉内的按钮（如 App 菜单）。
- 底部导航切换 Workspace、Agents、Files 和 Git。
- 对话框限制在可视区域并支持 Esc、遮罩关闭。
- Terminal、Chat 输入区和工具栏针对窄屏重新排布。
- Git Review 的 Changes 和 History 标签在窄屏下把文件/提交列表和 diff/详情改为纵向堆叠，同一时刻只显示其中一个：选中文件或提交后显示 diff/详情，通过 "Back to changes"/"Back to history" 按钮返回列表；列表本身在超出可视高度时可在面板内部滚动，不会把下方的提交输入区挤出屏幕。History 在移动端不会自动展开第一条提交。
- Terminal 底部提供触屏按键栏（Esc、方向键、Tab、Shift+Tab、Ctrl+C、Ctrl/Alt 粘滞修饰键、Enter、粘贴、历史与收藏命令）。按设备判断而不只看宽度：窄屏手机、宽度超过 640px 的纯触屏设备（横屏手机、平板），以及在本设备上出现过手指或触控笔操作时都会显示（接了键盘、触控板或触控笔的平板会被浏览器识别为精确指针，只看媒体查询会漏掉）；终端 More 菜单可手动显示或隐藏，选择保存在本设备。显示时终端会在软键盘弹出时保持在键盘上方。

## 设计原则

- Pi 的视觉语言是默认基准，Agent 功能不创建割裂的第二套 UI。
- 高频操作直接可见，低频配置进入菜单。
- 动态状态不能遮挡输入按钮和工具栏。
- 图标必须具有 title、aria-label 和明确的选中状态。
- 面板收起后仍保留恢复入口。

## 验收标准

- 桌面布局拖动后刷新仍保持尺寸。
- 全屏/聚焦状态不会误触发浏览器 Fullscreen。
- 移动端页面宽度不超过 viewport，不出现横向溢出。
- 切换项目或标签不会丢失未发送草稿。
- 菜单不会被容器裁切，并能点击外部关闭。
- 拖动调整尺寸时即使窗口失焦或页面隐藏，也会恢复文本选择和鼠标样式。
